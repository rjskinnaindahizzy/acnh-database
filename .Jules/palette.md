## 2024-05-18 - Improve Global Focus States and Accessible Feedback Icons
**Learning:** Adding a global `:focus-visible` ensures that every interactive element receives a clear, high-contrast outline for keyboard users, catching many custom elements (like `div` or `span` buttons) that developers often forget to style. Furthermore, replacing generic text like "Retrying..." with `<span class="btn-spinner"></span>` explicitly links visual animation to the state. Wrapping text-adjacent decorative unicode or SVG elements (e.g. `✕`, `↻`) in `<span aria-hidden="true">` stops screen readers from repeating cryptic glyph names before the functional label, significantly reducing audio clutter.
**Action:** When adding icons to dynamic text content (`innerHTML`), wrap them with `<span aria-hidden="true">` by default unless they convey standalone semantic meaning. Apply a global fallback `:focus-visible` rule in all stylesheets.
